# برايت سمايل — عيادة أسنان

صفحة هبوط ثنائية اللغة (العربية RTL والإنجليزية LTR) لعيادة أسنان، مع قائمة علاجات بأسعار {{placeholders}}، ونموذج حجز زيارة مع تحقق وحفظ في localStorage، وآراء مرضى موسومة كعينة، وأسئلة شائعة.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## التقنية
React + TypeScript + Vite + Tailwind CSS، وأيقونات Phosphor.
